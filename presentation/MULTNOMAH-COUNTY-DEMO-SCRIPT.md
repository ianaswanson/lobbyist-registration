## 📊 BACKUP Q&A

### "What about SSO integration?"

> "Currently using email/password via NextAuth. SSO with Google Workspace or Azure AD is straightforward—about two weeks of work. Most counties prefer to launch with simple auth and add SSO later, but we can prioritize it if you need it from day one."

### "How do email notifications work?"

> "We have templates for welcome emails, password resets, registration approvals, deadline reminders, and violation notices. In the demo they're logged to the console. For production, we integrate with your email service—SendGrid, Mailgun, or county SMTP. Takes about two days."

### "What about backups?"

> "Cloud SQL provides automatic daily backups with 30-day retention. Point-in-time recovery lets you restore to any second in the last seven days. We can increase retention for compliance needs. High availability option provides 99.95% uptime."

### "Can we customize the branding?"

> "Absolutely. Color palette, logo, application name are all easily changed—takes about an hour. The county seal is already in the navigation. We can match any design guidelines you have."

### "How do you prevent duplicate registrations?"

> "Email uniqueness is enforced at the database level—one account per email. All registrations go through admin approval. If you need additional validation like SSN or license number, we can add that."

### "What if someone forgets to file?"

> "Automated reminders at 14 days before, 7 days before, and the day after the deadline. Admin dashboard shows overdue reports in red. Admin can issue violations for late filing."

### "Can employers file for multiple lobbyists?"

> "Yes. Each expense line item can specify a different lobbyist. One quarterly report covers all of them."

### "How do you handle amendments?"

> "Lobbyists can update registration info within 30 days. Expense reports—once approved—require admin approval to amend, preventing tampering. All changes are logged."
